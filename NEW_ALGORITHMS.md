# 🚀 NEW ALGORITHMS ADDED - PROGRESS REPORT

## ✅ Algorithms Implemented

### 1. **Selection Sort** 🎯
- **Status:** Complete & Live
- **Concept:** Finds the minimum element repeatedly.
- **Visuals:** Shows "Current" pass and "Minimum" pointer hunting for the smallest value.
- **Key Animation:** Elements highlight as they are compared against the current minimum.
- **Complexity:** O(n²) time, O(1) space.

### 2. **Insertion Sort** 📥
- **Status:** Complete & Live
- **Concept:** Builds a sorted array one item at a time.
- **Visuals:** "Key" element slides backwards into its correct position.
- **Key Animation:** Shows elements shifting to the right to make space for the key.
- **Complexity:** O(n²) time, O(1) space (but O(n) for nearly sorted!).
